# Fikret Yüksel Foundation Scoop bucket

```powershell
scoop bucket add fikretyukselit https://github.com/fikretyukselit/scoop-bucket
scoop install frc-mcp
```

`bucket/frc-mcp.json` is written by `.github/workflows/update.yml` from the latest
[frc-mcp](https://github.com/fikretyukselit/frc-mcp) release, hourly, and only after the release's `checksums.txt`
verifies against the frc-mcp release workflow's keyless Sigstore signature. Do not edit it by hand.
